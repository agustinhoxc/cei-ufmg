Como funciona o Agente

Agente CEI

A inteligência conversacional do ecossistema de inovação da UFMG. Não um chatbot dentro do site, mas a interface de um sistema de inteligência, conexão e governança.

A grande mudança conceitual

De “Como podemos ajudá-lo?” para “Conte-nos o que você está tentando realizar.”

O objeto da governança deixa de ser a demanda isolada e passa a ser a trajetória.

A trajetória produz dados.

Cada etapa registra contexto, conexões e resultados.

Os dados produzem combinações.

Elementos dispersos do ecossistema se encontram.

As combinações produzem alternativas.

Possibilidades de ação, não respostas prontas.

As alternativas subsidiam decisões.

Pessoas decidem com evidências.

As decisões produzem resultados.

Projetos, negócios, parcerias e impacto.

Os resultados voltam ao sistema.

O ecossistema aprende.

Arquitetura técnica

Pronto para integração.

Nesta versão, as respostas são simuladas no navegador, a partir da base de conhecimento do projeto do CEI. Nenhum dado é enviado.

A camada assets/js/agent.js é desacoplada da interface. Para conectar uma API real, basta definir o endpoint:

var CEI_AGENT_ENDPOINT = null;
// → "https://api.seu-dominio/agente"
// POST { message, history }
// ← { understanding, diagnosis, problem,
//     dimensions[], connections[], next, owner }
